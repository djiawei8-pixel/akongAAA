# 自动化入口（预留）

当前没有运行脚本、定时任务、API 调用或 Agent 调度，也不会消耗模型额度。
本目录不改变 ChatGPT 内已有的定时任务，不启动电脑上的四个会话。

## 适合以后逐项增加的能力
1. 本地检查 Markdown 链接与任务必填字段。
2. 将已完成任务汇总成周报草稿。
3. 接入获授权的数据源，生成待复核报告。

## 接入约定
每项自动化单独建子目录，提供 README、入口脚本及配置示例；只有出现实际需求时再添加。
说明：输入路径、输出路径、手动运行方法、依赖、预计调用成本、失败处理与负责人。
默认手动触发，先做只读或草稿输出；需要定时运行时明确频率、时区与停用方法。
重复运行不得重复发消息或覆盖人工确认的数据；网络请求要限制重试，失败写入任务记录。
密钥由环境变量或安全凭据服务注入，禁止提交真实 .env。
任何发送消息、改价、广告投放等外部动作都须遵循对应任务授权。
