# Market & Data

负责马来西亚家清竞品观察、价格与内容表现分析，输出可执行结论。

## 输入
[任务文件](../tasks/README.md)、[SKU 卡](../skus/README.md)、获授权且适合公开的资料。

## 最小报告格式
保存为 `YYYY-MM-DD-sku-topic.md`：
- 研究问题与采集时间（Asia/Kuala_Lumpur）。
- 来源链接、平台、规格、币种 MYR、标价/活动价/券后价、运费口径。
- 销量或视频数据的统计窗口；无法观察的字段注明缺失。
- 发现、局限及建议测试；区分事实和推断。
- 交接给 Content / Creator 的具体输入。

对比价格先统一容量或数量。视频表现需考虑发布时间，刚发布的数据不要直接和成熟视频比较。
没有可靠来源时不补造数值；报告摘要与产出链接回填原任务。
