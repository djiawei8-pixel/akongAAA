## 维护规则
Lead 负责确认产品事实，其他岗位引用。公开包装、官方说明与测试证据需标注版本和确认日期。
“已核实”只适用于已提供证据的字段，不代表整张卡已获验证。
价格、库存和活动条款需注明有效时间；本库不录入采购成本或未公开定价。
新增 SKU 可复制现有卡片结构，同时更新本索引。
