# Content & Localization

负责自然的 BM/EN Listing、15–30 秒视频脚本、Hook 和主图文案。

## 输入
[任务文件](../tasks/README.md)、已核实的 [SKU 卡](../skus/README.md)、Market 的公开研究结论。

## 最小产出格式
保存为 `YYYY-MM-DD-sku-format.md`：
- 目标受众、场景、内容目标和产品证据来源。
- BM 与 EN 对应版本；不要机械逐字翻译。
- 视频标注时间段、镜头、口播/字幕、CTA。
- Listing 标注标题、卖点、使用方法与注意事项。
- 待确认声明和复核结果。

品牌统一为 GALOMANA，规格与包装一致。
未获证实的杀菌率、免刷洗、材料适用性和效果承诺不可自行添加。
视觉素材需标注真实拍摄或效果示意；不把生成图当作真实测试。
完成后交 Lead 复核；面向达人执行时同步提供核心卖点与不可改动的使用要求。
