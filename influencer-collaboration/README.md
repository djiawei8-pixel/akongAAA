# Influencer Collaboration

负责达人筛选标准、BM/EN 邀约草稿、内容 brief 与交付跟踪。

## 输入
[任务文件](../tasks/README.md)、[SKU 卡](../skus/README.md)、获复核的内容稿。

## 最小产出格式
保存为 `YYYY-MM-DD-sku-creator-brief.md`：
- 合作目标、目标受众、匹配依据。
- 产品核心卖点及证据；必须展示的场景和使用步骤。
- 视频数量、长度、时间安排与验收标准（未确认写待定）。
- BM/EN 沟通草稿；佣金、预算、样品安排均以当前授权为准。
- 交付状态、作品链接、下一步。

## 记录边界
公开仓库仅存公开作品链接或匿名代号，例如 Creator-001。
联系方式、收件地址、合同、广告授权码和非公开商务条件留在获授权的私有记录。
对外联系需要用户授权；不要将草稿标成已发送，将申请标成已通过，或将交付标成已验收。
