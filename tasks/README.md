# 任务入口

复制 [TEMPLATE.md](TEMPLATE.md)，命名为 `YYYY-MM-DD-role-topic.md`。
role 使用 lead、market、content、creator。模板本身不是待执行任务。

| 状态 | 含义 |
| --- | --- |
| Todo | 目标和验收标准已填写，待领取 |
| Doing | 主负责人正在执行 |
| Blocked | 缺少输入；填写原因与恢复条件 |
| Review | 产出已提交，等待 Lead 验收 |
| Done | 验收通过，结果和交接已记录 |

同一任务只在此文件维护状态。小任务不拆子任务；确需跨岗位时由 Lead 建立独立任务并互相链接。
