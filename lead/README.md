# Lead

负责确定优先级、拆解必要任务、解决资料冲突与最终验收。

## 工作顺序
1. 明确业务问题、SKU、截止时间与交付标准。
2. 从 [任务模板](../tasks/TEMPLATE.md) 建立任务，指定一个主负责人。
3. 检查输入是否足够；先补事实，再写对外内容。
4. 复核产出与证据，在任务文件记录决定并关闭任务。

## 保存内容
重要跨任务决策可保存为 `YYYY-MM-DD-decision-topic.md`，写明问题、决定、依据、适用范围和复查条件。
单一任务的决定直接记录在任务文件，避免重复文档。

## 可按需派发的起步工作
- 核实一个 SKU 的产品卡。
- Market：整理同规格竞品的公开价格与来源。
- Content：依据已核实产品卡制作一组 BM/EN Listing 草稿。
- Creator：依据内容草稿准备达人 brief 与验收标准。
以上为建议队列，尚未创建或执行任务。
